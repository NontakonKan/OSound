# rust_os

ระบบปฏิบัติการ (OS) ที่เขียนเองด้วย Rust ทีละบรรทัด สำหรับเครื่อง x86_64
เรียนตามลำดับบทของ [Writing an OS in Rust](https://os.phil-opp.com/) (Second Edition)
แล้วต่อยอดไปจนมี **GUI ที่ออกแบบเอง**

---

## 📍 สถานะตอนนี้

```
บทที่ 2 — A Minimal Kernel
  ✅ A ใบสเปกเครื่อง (x86_64-rust_os.json)
  ✅ B ตั้งค่า Cargo (.cargo/config.toml)
  ✅ C bootloader + บูตใน QEMU ได้
  ⬜ D พิมพ์ Hello World ลงจอ VGA   ← อยู่ตรงนี้
```

**เหลืออีก 19 บทจะถึง GUI แบบมีหน้าต่างและเมาส์**
(บทเรียนหลัก 11 บทรวมบทที่ 2 ที่เหลืออยู่ + สาย GUI อีก 8 บท)

---

## 🗺️ แผนที่ทั้งหมด

```
ช่วงที่ 1: ฐานราก (บท 1–4)       → บูตได้ พิมพ์ข้อความได้ ทดสอบได้
ช่วงที่ 2: รับมือฮาร์ดแวร์ (บท 5–7)  → จัดการ error ของ CPU, รับคีย์บอร์ด, ตัวจับเวลา

ช่วงที่ 4: ทำหลายงานพร้อมกัน (บท 12) → async/await
━━━━━━━━━━━━━━ จบบทเรียนหลัก ━━━━━━━━━━━━━━
ช่วงที่ 5: GUI (บท 13–20)          → จอกราฟิก, ฟอนต์, เมาส์, หน้าต่าง, เดสก์ท็อป 🖥️

```

## ช่วงที่ 6: ต่อยอดได้อีก (เลือกตามความสนใจ)

| หัวข้อ | ทำให้ OS ทำอะไรได้ |
|---|---|
| User mode + system calls | แยกโปรแกรมผู้ใช้ออกจาก kernel โปรแกรมพังแล้วไม่ลาม OS |
| Preemptive multitasking | สลับงานด้วย timer โปรแกรมไหนค้างก็ไม่ทำให้ทั้งเครื่องค้าง |
| โหลดโปรแกรม (ELF loader) | รันแอปที่คอมไพล์แยกจาก kernel ได้ |
| ระบบไฟล์ (FAT32) + ไดรเวอร์ดิสก์ | เก็บและเปิดไฟล์ได้จริง |
| PCI + virtio | ค้นหาอุปกรณ์ในเครื่อง และใช้ไดรเวอร์จอ / ดิสก์ / เน็ตที่เร็วขึ้น |
| Networking | ต่ออินเทอร์เน็ต (TCP/IP) |
| Multi-core (SMP) | ใช้ CPU หลายคอร์ |
| สาย Embedded / RTOS | นำความรู้บท 1, 5–7 และ 12 ไปใช้กับไมโครคอนโทรลเลอร์ (STM32, ESP32, Pico) ผ่าน Embassy / RTIC |

## 🛠️ วิธี build และรัน

ต้องมี: Rust **nightly**, `rust-src`, `llvm-tools-preview`, QEMU, `bootimage`

```sh
rustup override set nightly
rustup component add rust-src llvm-tools-preview
brew install qemu
cargo install bootimage

cargo run          # build แล้วเปิด QEMU
cargo bootimage    # สร้างไฟล์ดิสก์บูตได้อย่างเดียว
```

ไฟล์ดิสก์ที่ได้อยู่ที่ `target/x86_64-rust_os/debug/bootimage-rust_os.bin`

### ⚠️ จุดที่ต่างจากบทความต้นฉบับ (nightly 1.101, ตุลาคม 2026)

| ไฟล์ | ต้นฉบับ | ที่ใช้ได้จริงตอนนี้ |
|---|---|---|
| `x86_64-rust_os.json` | `"target-pointer-width": "64"` | ต้องเป็นตัวเลข `64` และ `target-c-int-width` ต้องเป็น `32` ด้วย |
| `x86_64-rust_os.json` | (ไม่มี) | ต้องเพิ่ม `"rustc-abi": "softfloat"` |
| `.cargo/config.toml` | (ไม่มี) | ต้องเพิ่ม `json-target-spec = true` ในหมวด `[unstable]` |
| `src/main.rs` | `#[no_mangle]` | edition 2024 ต้องเขียน `#[unsafe(no_mangle)]` |
| `Cargo.toml` | `bootloader = "0.9"` | ยังใช้ 0.9 อยู่ (ห้ามใช้ 0.11 จนกว่าจะถึงบทที่ 13) |

## 📂 โครงสร้างโปรเจกต์

```
rust_os/
├── Cargo.toml              ← ข้อมูลโปรเจกต์ + crate ที่ใช้
├── x86_64-rust_os.json     ← สเปกเครื่องเป้าหมาย (PC ที่ไม่มี OS)
├── .cargo/config.toml      ← บอก Cargo ให้ build ให้เครื่องนี้ และรันด้วย QEMU
└── src/
    └── main.rs             ← kernel
```
